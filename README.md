# CS_HANGMAN
## The Corporate Gatekeeper

> **Learn computer science. Complete challenges. Earn your clearance.**

CS_HANGMAN is a gamified computer science learning platform that combines an atmospheric corporate-horror game experience with programming education, coding practice, technical challenges, and learner progression.

The platform transforms learning into an interactive journey. Players explore computer science topics, complete coding exercises, solve technical challenges, earn experience points, unlock achievements, and develop practical software engineering knowledge.

## 1. Project Overview

CS_HANGMAN — The Corporate Gatekeeper — is an interactive learning game designed to make computer science more engaging and accessible.

Players enter a fictional corporate environment where technical knowledge is the key to progression. Each department introduces learning activities and challenges that help develop programming knowledge, problem-solving ability, and software engineering skills.

The application brings together traditional learning materials and game mechanics in one experience.

### Project Goals

- Make computer science learning more interactive.
- Encourage consistent coding practice.
- Teach programming concepts through practical examples.
- Improve technical vocabulary and conceptual understanding.
- Reward learning milestones and continued progress.
- Provide an engaging environment for beginner and intermediate learners.

### Main Application Areas

| Area | Description |
|---|---|
| Command Center | Main dashboard and navigation |
| Challenge Terminal | Hangman-style computer science challenges |
| Coding Academy | Structured lessons and learning tracks |
| Code Workshop | Coding, debugging, and code-review exercises |
| Engineering Lab | Practical technical decision challenges |
| Departments | Themed learning areas |
| Technical Receipts | Activity and learning history |
| Engineer Profile | XP, achievements, and progress |

## 4. Code Workshop

The Code Workshop provides practical coding-related learning activities.

It contains **150 exercises** focused on developing the habits and skills used in software development.

### Exercise Categories

**Coding Practice**

Learners explore programming logic, functions, loops, variables, data structures, and problem-solving techniques.

**Debugging Practice**

Learners inspect code, identify problems, understand unexpected behavior, and evaluate possible corrections.

**Code Review**

Learners examine code quality, readability, maintainability, and potential improvements.

### Learning Tools

- Exercise descriptions.
- Difficulty levels.
- Search and filtering.
- Helpful hints.
- Reference solutions.
- Explanation of coding concepts.
- Progress tracking.

### Suggested Workflow

1. Select an exercise.
2. Read the requirements.
3. Identify the expected behavior.
4. Attempt the problem.
5. Review hints when needed.
6. Compare the result with the reference solution.
7. Understand why the solution works.

The Workshop is designed as a guided coding-learning environment. Learners can use a local IDE or a trusted coding sandbox for unrestricted program execution.

## 6. Game Mechanics and Progression

CS_HANGMAN uses game mechanics to make continued learning rewarding.

### Experience Points

Learners earn XP by completing supported learning activities and challenges.

XP represents participation and progress within the game rather than a formal academic grade.

### Accuracy

Accuracy indicators help learners understand their performance during challenge activities.

### Streaks

Streaks encourage consistent learning habits and repeated engagement.

### Achievements

Badges and achievements recognize milestones and completed activities.

### Engineer Profile

The Engineer Profile provides an overview of the learner's progression, rewards, and learning activity.

### Technical Receipts

Technical Receipts provide an activity-oriented history that helps learners review completed tasks and previous progress.

## 8. Installation and Setup

### Requirements

Install the following before starting development:

- Node.js (current supported LTS version).
- npm.
- Git.
- A code editor such as Visual Studio Code.

Check your installation:

```bash
node --version
npm --version
git --version
```

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/CS_HANGMAN.git

cd CS_HANGMAN
```

Replace `YOUR-USERNAME` with the GitHub account or organization that owns the repository.

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open the local URL printed in the terminal.

### Build for Production

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```

Available project scripts can be inspected with:

```bash
npm run
```
